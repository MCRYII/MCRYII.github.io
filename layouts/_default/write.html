📝 推荐流程

  1. 运行本地写作助手：python blog_tool.py
  2. 新建文章 → 填写标题/分类/标签 → 选择并裁剪封面
  3. 用 Markdown 写正文，插入图片，预览确认
  4. 保存 → 本地预览 → 一键推送到 GitHub

📄 Front Matter 说明

  • title 文章标题（必填）
  • date 发布时间，格式 2026-06-06T21:24:37+08:00
  • categories / tags 分类与标签数组
  • draft 草稿标记，true 时本地可见、线上不发布
  • cover.image 封面图路径（推荐 5:3）

🖼 图片与封面

图片放在 static/images/，正文用 ![](/images/文件名) 引用；封面可在写作工具里裁剪成 5:3。
