```c++
// 第 1 - 3 行：定义引脚和参数
#define POT       26      // 定义一个叫 POT 的常量，值为 26（接电位器的引脚）
#define LED       13      // 定义一个叫 LED 的常量，值为 13（接LED的引脚）
// #define CHANNEL   0     // 这行被注释掉了（前面有 //）。因为新版库自动分配通道，不需要我们手动定义

// 第 5 行：声明全局变量
int pot_value;            // 声明一个整型变量，用来存放每次读取到的电位器数值（0~4095）

// ==================== setup 函数（只运行一次）====================
void setup() {
  // 第 8 行：初始化串口通信
  Serial.begin(9600);     // 开启串口，波特率设为 9600。虽然这代码没打印数据，但留着方便你日后调试查看数值

  // 第 10 行：设置 ADC（模数转换器）的精度
  analogReadResolution(12); 
  // ESP32 的 ADC 默认是 12 位，范围 0~4095。如果你不写这行，默认也是 12，写了更保险。
  // （如果是 Arduino Uno，它是 10 位，范围 0~1023）

  // 第 12 行：配置 ADC 的衰减器（输入电压范围）
  analogSetAttenuation(ADC_11db);
  // 这行是 ESP32 特有的。不设置的话，ADC 最大只能测到约 1.1V。
  // 设置为 ADC_11db 后，才能读取 0V ~ 3.3V 的全范围电压。电位器接 3.3V，所以必须加这行。

  // 第 15 行：核心修改点！绑定 LED 引脚并设置 PWM 参数
  ledcAttach(LED, 1000, 12);
  // 这个函数干了两件事（替代了老版的 ledcSetup + ledcAttachPin）：
  // 参数1（LED = 13）：指定要输出 PWM 的引脚。
  // 参数2（1000）：PWM 的频率，单位 Hz，这里设为 1kHz。
  // 参数3（12）：PWM 的分辨率，12 位，意味着占空比可调范围是 0 ~ (2^12 - 1) = 0 ~ 4095。
  // 注意：这个函数会自动帮你分配一个空闲的硬件通道，不用你操心。
}

// ==================== loop 函数（无限循环执行）====================
void loop() {
  // 第 18 行：读取电位器的模拟值
  pot_value = analogRead(POT);
  // 读取 GPIO 26 脚的电压，将其从模拟信号（电压）转换成数字值。
  // 电压 0V 对应 0，电压 3.3V 对应 4095。中间按比例变化。

  // 第 20 行：输出 PWM 信号控制 LED 亮度
  ledcWrite(LED, pot_value);
  // 向引脚 13 输出 PWM 方波。
  // 参数1（LED = 13）：指定引脚。
  // 参数2（pot_value）：决定占空比。因为上面 PWM 分辨率设的是 12 位，范围 0~4095，
  // 而 pot_value 正好也是 0~4095，所以数值完美匹配，直接丢进去就行，不需要 map() 换算！
  // 数值 0 时，LED 完全熄灭；数值 4095 时，LED 最亮。

  // 第 22 行：短暂延时
  delay(50);
  // 让程序暂停 50 毫秒（0.05 秒）。
  // 作用：一来避免 loop 跑得太快导致 LED 闪烁人眼察觉不到；二来给 ADC 充足的采样时间。
}
```

### 1. ADC（模数转换器）—— 充当“眼睛”和“尺子”

**它负责“看”和“测量”。**
自然界的光、声音、电压都是**连续变化**的（模拟信号）。但单片机（ESP32）是个“死脑筋”的数字芯片，它只认识 **0 和 1**（数字信号）。

- **ADC 的作用**：就是一把**尺子**，把外面连续变化的电压（比如 0V ~ 3.3V），量成一个具体的数字，告诉单片机。
- **代码里的体现**：`analogRead(POT)` 就是拿着这把尺子去量电位器中间的电压。
- **12位分辨率什么意思**：这把尺子上有 **4096** 个刻度。0V 对应刻度 0，3.3V 对应刻度 4095。电压变高一点点，刻度数字就加 1。

> **通俗理解**：ADC 就像你的**眼睛**。你看一杯水，能看出“水位在杯子一半高的位置”。ADC 就是帮单片机“看”电压高低的器官。

------

### 2. PWM（脉冲宽度调制）—— 充当“快手上”和“快手下”

**它负责“假装”输出一个连续变化的电压。**
ESP32 的数字引脚其实只有两个状态：**要么输出 3.3V（开）**，**要么输出 0V（关）**。它天生不能输出 1.5V 或 2.0V 这样的中间电压。

- **PWM 的骚操作**：既然变不了电压，那我就**极快地开关开关**（每秒开关几千次）。
- **骗过你的眼睛和电子元件**：如果 100% 的时间都开着 → 灯最亮；如果 80% 的时间开着，20% 的时间关着（但开关极快，人眼反应不过来）→ 灯看起来就是 **80% 的亮度**。
- **代码里的体现**：`ledcWrite(LED, pot_value)` 就是控制这个“开”的时间比例。这个比例就叫**占空比**。

> **通俗理解**：PWM 就像你**疯狂地按电灯开关**。按得极快，快到手抽筋。如果一直按着（全开）最亮；如果按一下松一下（各占一半），灯光看起来就是一半亮。ESP32 就是那个替你“光速按开关”的机器人。

------

### 3. 为什么你的代码里它俩是“绝配”？

在你这套代码里，**ADC（眼睛）** 看到了电位器旋钮的位置，读出了一个数字（0~4095）。
然后，它直接把**这个数字原封不动**递给了 **PWM（按开关的手）**。

正因为你把 ADC 的分辨率设成了 **12位（0~4095）**，同时把 PWM 的分辨率也设成了 **12位（0~4095）**，所以：

- 眼睛看到最大（4095）→ 手就全开（最亮）。
- 眼睛看到中间（2000）→ 手就按 2000/4095 的比例开（中亮）。

**这就是为什么不需要写 `map()` 函数去换算的原因**——因为它们的“刻度尺”完全一模一样，完美对接！
